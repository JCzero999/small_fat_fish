## A1. active_goals 支持 deadline + 到期主动提醒

### 数据变更
- [ ] `SelfState.active_goals` 从 `list[str]` 升级为结构化：
  ```python
  @dataclass
  class ActiveGoal:
      text: str
      deadline: str | None = None      # ISO8601 或相对描述解析后的绝对时间
      created_at: str = ""
      source_memory_id: str | None = None
      status: str = "open"             # open | reminded | done | expired
  ```

- [ ] 旧库 `list[str]` 自动迁移为 `ActiveGoal(text=..., deadline=None)`
- [ ] `update_self_state` 在抽取时识别「约定/提醒我/到时候」类语句，尝试解析 deadline

### 主动开口接入
- [ ] `should_proactive_open` / `build_proactive_prompt` 新增优先级：

  4. 忽然想起（A2）

### 测试

## A2. 「忽然想起」由头类型

### 逻辑
- [ ] 新增函数 `pick_sudden_recall(brain, peer_id, now) -> Memory | None`
  - 候选：高牢固度（或当前高 activation + 非归档）的 Episodic / 重要 Semantic
  - 只取本 peer、非冻结、非最近 7 天已想起过的
  - 每日额度：默认最多 2 条；安静时段不触发
- [ ] 主动开口决策链中，当无更高优先级由头时，以一定概率（可配，默认 15–25%）插入「忽然想起」由头
- [ ] `build_proactive_prompt` 输出明确标签，例如：`[忽然想起] 上次你提到……`

### 配置
- [ ] `ProactiveConfig` 或独立配置增加：
  - `sudden_recall_enabled: bool = True`
  - `sudden_recall_daily_limit: int = 2`
  - `sudden_recall_cooldown_days: int = 7`
  - `sudden_recall_probability: float = 0.2`

### 测试
- [ ] 单测：冷却、额度、安静时段、无候选时返回 None
- [ ] 真实联测：多日互动后，在合适时机主动提起旧事

# 方案 B：FSRS 风格牢固度（v0.12.0）

**目标**：记忆「想起就牢、久不提就淡、淡到阈值就冻结但仍可被工具查到」。  
与现有七因子正交：七因子管「留不留、留在哪档」；牢固度管「当前多容易被想起」。

---

## B1. 数据模型

- [ ] SemanticMemory / EpisodicMemory 新增：
  ```python
  stability: float = 1.0       # 稳定度（越高衰减越慢）
  retrievability: float = 1.0  # 当前可提取度（0–1）
  last_review: str | None = None
  review_count: int = 0
  frozen: bool = False         # 低于阈值后冻结
  ```
- [ ] 旧库缺省安全：`stability=1.0, retrievability=1.0, frozen=False`
- [ ] 核心条目、protected、未平复情感事件、带 deadline 的约定：**永不自动冻结**

---

## B2. 更新规则（简化 FSRS 思想，不必完整实现 FSRS-5）

- [ ] **想起（成功注入或工具命中）**：
  - `review_count += 1`
  - `stability` 提升（公式可简化：`stability = min(max_s, stability * (1 + gain))`）
  - `retrievability = 1.0`
  - 若曾 frozen → 解冻
- [ ] **时间流逝（巩固或定时任务时批量算）**：
  - `retrievability = exp(-elapsed_days / stability)`（或等价简化）
  - 若 `retrievability < freeze_threshold`（默认 0.35）且非保护项 → `frozen = True`
- [ ] **冻结效果**：
  - 自动注入 / 忽然想起 **跳过** frozen 记忆
  - `search` / 工具 / `/memory list` **仍可查到**（可标注「已淡忘」）
- [ ] 同一记忆在 `review_window`（默认 24h）内多次想起只算一次加固
