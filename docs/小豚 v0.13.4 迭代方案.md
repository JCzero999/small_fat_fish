# 小豚 v0.13.1 迭代方案  
## 统一人设 + 记忆使用规则（消掉「汇报感」）

> **落地说明（2026-11-07）**：本方案文件名为《v0.13.4》，正文标题沿用写作时的 v0.13.1；
> 因 v0.13.1 已被「记忆互通」占用，**实际发布版本号定为 `0.13.4`**（见 CHANGELOG）。
> 交付状态：D1–D4 全部落地并通过 316 项测试 + 真实 LLM 五句语气回归。

**版本号：`v0.13.1`**  
**目标：** Chat Shell 与 QQ **同一套身份与记忆用法**，默认像聊天，不像交记忆作业。  
**不包含：** 方案 C、自动课表、换模型、大改 UI 视觉。

---

## 0. 问题锚定（来自你的实测）

| 现象 | 根因假设 |
|------|----------|
| Shell：「我记着呢」「这个我还能记错？」 | 人设/注入强调「必须体现记得」→ 记忆表演 |
| QQ：可认怂、更松 | 另一套提示或更短注入 |
| 两边都是「小豚」却气质分裂 | **人设源不唯一** + **记忆使用规则未写成硬约束** |

成功标准：同一 peer、同类问题，两边都 **用得着再提记忆、不宣誓、不确定就说不确定**。

---

## 1. 第一性原理（本版必须遵守）

1. **单一人设源**：磁盘上只有一份正文，Shell 与 QQ 都读它。  
2. **记忆是材料不是考题**：注入提供事实；禁止「为证明而复述」。  
3. **通道只改传输，不改人格**：QQ / Shell 不得各写一套口吻。  
4. **可回归**：用固定三句测试题，两边各跑一遍可对比。

## 2. 交付物

### D1. 人设正文（唯一源）

路径建议：`persona/xiaotun_v1.md`（或 `user_config` 仅存路径指针）

**必须包含的「记忆使用」专节（可直接贴进文）：**

```text
【记忆怎么用】
- 下面或系统里的「长期记忆」是你可能用到的材料，不是答题卡。
- 只有当前对话用得上时才提；不要主动罗列作息、称呼、旧事来证明自己记得。
- 禁止套话：「我记着呢」「我记得很清楚」「这个我还能记错」「我不会忘」。
- 不确定、对不上、注入里没有：就说没印象或不确定，可以请对方补一句，不要编。
- 关心对方时用自然语言，不要把档案条目背诵出来。
- 你是在聊天，不是在汇报记忆同步状态。
```

**同时保留（短）：** 身份、与用户关系、短句节奏、工具诚实、安全入口。  
全文建议仍 **≤1500 字**，避免挤占注入预算。

### D2. 注入脚注（机器侧，两端统一）

每次 `build_injection` 产物末尾固定追加（可配置开关，**默认开**）：

```text
【使用约定】以上为检索到的记忆材料。请按需取用，勿逐条汇报；勿使用「我记着呢」等证明式套话；没有的信息请承认不确定。
```

### D3. 通道接入说明

| 通道 | 要求 |
|------|------|
| Chat Shell | system = 人设全文 + inject（含脚注）+ 安全摘要 |
| QQ / AstrBot | **同一人设文件**；禁止插件内另写长人设；仅允许通道相关的极短规则（如「群聊少回」） |

### D4. 回归剧本 `scripts/persona_memory_tone_check.md`

固定用户句（两端各测）：

1. 「我是谁」  
2. 「我一般几点睡 / 你记得我作息吗」  
3. 「你还记得一件从未写入的事吗」（应不确定）  
4. 闲聊两句（「在干嘛」「有点累」）——应短、不背档案  

**失败模式：** 出现「我记着呢 / 还能记错 / 逐条报作息」→ 本版未通过。
