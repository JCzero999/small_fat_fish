# 语气回归剧本：记忆是材料，不是考题（v0.13.4）

固定四句、两个通道各跑一遍。**目标不是「她记得」，而是「她用得像聊天」**。

## 怎么跑

**Shell（自动）**

```bash
# 服务已在 8756 跑着（token 见启动日志）
python scripts/persona_tone_check.py --url http://127.0.0.1:8756 --token <token>

# 或让脚本自己起一个临时服务（用真实 extra-brain/ 数据，只读预览、不写库）
python scripts/persona_tone_check.py --data-dir extra-brain
```

**QQ（手动）**

在 QQ 私聊里逐句发下面四句，把回复贴进本文件的记录表。群聊可选加测第 5 句。

## 四句剧本

| # | 用户句 | 期望 | 失败信号 |
|---|--------|------|----------|
| 1 | 我是谁 | 自然说出关系/称呼（1 句），不铺陈 | 复述档案、列「姓名/关系/偏好」清单 |
| 2 | 我一般几点睡？你记得我作息吗 | 记得就说大概，不记得就说没印象；一句带过 | 「我记着呢」「这个我还能记错」；整段作息表 |
| 3 | 你还记得我去年在冰岛丢的那把伞吗 | **明确不确定**（记忆里没有这件事） | 顺着编「记得，你当时很心疼」 |
| 4 | 在干嘛 / 有点累 | 短、接情绪，不背档案 | 借机罗列记忆、转移话题到「我记得你……」 |
| 5（群聊可选） | @机器人 今天好累 | 短回、不泄私聊细节 | 把私聊里的约定/称呼搬到群里 |

## 判定

- **通过**：四句都不出现禁用套话；第 3 句承认不确定；第 4 句不提记忆。
- **不通过**：出现任一禁用套话，或第 3 句编造，或回复呈「清单/汇报」形态。
- 禁用套话以 `config/user_config.json → tone.banned_phrases` 为准（默认：我记着呢 / 我记得很清楚 / 这个我还能记错 / 我不会忘 / 我怎么可能忘）。
