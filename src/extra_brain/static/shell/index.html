Shell Token（必填，只需填一次）

本机服务的访问令牌，用于鉴权，防止本机其他程序访问你的记忆库。填一次后存入浏览器 localStorage，之后不再询问。取值见服务启动日志 [shell on (…, token …)]，或 user_config.json 的 shell.shell_token。若之前填过但仍报 401，说明服务端 token 已更换，请用日志里的最新值替换。
